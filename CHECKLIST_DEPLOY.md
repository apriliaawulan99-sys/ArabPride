# Checklist Publikasi ArabPride

## Sebelum unggah
- [ ] ZIP sudah diekstrak.
- [ ] `public` berisi `index.html`, `style.css`, `app.js`.
- [ ] `vercel.json` berada di folder utama.
- [ ] Tidak ada data pribadi siswa atau API key.
- [ ] Materi dan kunci jawaban ditelaah guru.

## Vercel
- [ ] Login dengan GitHub.
- [ ] Repository yang benar diimpor.
- [ ] Root Directory adalah folder utama.
- [ ] Output Directory `public` jika diminta.
- [ ] Deployment berstatus Ready.

## Setelah online
- [ ] Beranda dapat dibuka.
- [ ] Semua tab berfungsi.
- [ ] Kuis dapat diperiksa.
- [ ] Teks Arab terbaca di desktop dan ponsel.
- [ ] Domain website dicatat.

## Sebelum dipakai siswa
- [ ] Guru memvalidasi materi.
- [ ] Kebijakan privasi ditetapkan.
- [ ] Audio memiliki izin penggunaan.
- [ ] Fitur yang belum tersedia tidak diklaim sudah aktif.
